# BiLSTM / GRU / TextCNN 网络结构对比

## 共同点

- 都用于文本情感二分类。
- 输入都是分词后的 token id 序列。
- 都先经过 Embedding 层，把词 id 转成词向量。
- 最后都接 Dropout 和 Linear 分类层。
- 都输出 `(batch, num_classes)` 的 logits。

## BiLSTM

- LSTM 按时间步逐词读取文本。
- 每个时间步接收当前词向量 `x_t`、上一时刻隐藏状态 `h_{t-1}` 和细胞状态 `c_{t-1}`。
- 通过遗忘门、输入门、候选状态、输出门更新状态。
- 遗忘门决定保留多少旧信息。
- 输入门决定写入多少新信息。
- 细胞状态 `c_t` 负责长期记忆传递。
- 隐藏状态 `h_t` 负责当前时间步输出。
- BiLSTM 同时做正向和反向扫描。
- 最后拼接前向最终隐藏状态和后向最终隐藏状态，再送入分类层。
- 优点是上下文建模强；缺点是结构复杂、训练较慢。

## GRU

- GRU 也是按时间步逐词读取文本。
- 每个时间步接收当前词向量 `x_t` 和上一时刻隐藏状态 `h_{t-1}`。
- GRU 没有单独的细胞状态 `c_t`，只传递隐藏状态 `h_t`。
- 更新门决定保留多少历史信息。
- 重置门决定计算当前候选状态时使用多少旧信息。
- 新隐藏状态由旧隐藏状态和候选隐藏状态加权得到。
- 相比 LSTM，GRU 门控更少，参数更少。
- 优点是训练更快；缺点是表达能力通常略弱于 LSTM。

## TextCNN

- TextCNN 不逐步传递隐藏状态。
- 它把整句词向量看成一个二维矩阵。
- 不同大小的卷积核在句子上滑动。
- 例如卷积核大小为 3、4、5 时，分别捕捉 3-gram、4-gram、5-gram 短语特征。
- 每个卷积核提取一种局部模式。
- 卷积后经过 ReLU 激活。
- 再通过 max pooling 选出最强特征。
- 多个卷积核的池化结果拼接后进入分类层。
- 优点是训练快、擅长抓关键词；缺点是长距离依赖建模弱。

## 核心区别

| 模型 | 状态传递 | 关键结构 | 主要优势 |
| --- | --- | --- | --- |
| BiLSTM | `h_t` 和 `c_t` 随时间传递 | 遗忘门、输入门、输出门、双向扫描 | 上下文建模强 |
| GRU | 只传递 `h_t` | 更新门、重置门 | 更轻量，训练更快 |
| TextCNN | 不传递时间状态 | 多尺度卷积、max pooling | 局部关键词提取强 |

## 简要结论

- 如果 BiLSTM 最好，说明上下文顺序信息重要。
- 如果 GRU 接近 BiLSTM，说明复杂 LSTM 不是必须的。
- 如果 TextCNN 表现很好，说明任务主要依赖局部关键词和短语。
